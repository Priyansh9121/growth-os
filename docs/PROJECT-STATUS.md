## If you are a new session starting here

Every session in this project begins with no memory of the previous one. Three
things matter before you touch anything:

1. **`AGENTS.md` governs, and §0 is not a formality.** Verify HEAD, `git status
--short` and the test suite before you work and again before you summarise.
   The project's own history is the argument: five dev logs record a previous
   log's stated remaining work being wrong. Prose in this repository — including
   this file — is evidence about the past, not about the tree in front of you.

2. **The tree is green and every package is independently green.** All 11
   workspaces typecheck and lint standalone; `npm run verify:all` exits 0. That
   is the baseline you must not break, and it is cheap: the whole suite runs in
   8.5 s without a database. Run it constantly rather than at the end.

3. **The crawler is the only Stage 4 work and it has no caller.** Robots,
   sitemaps, the frontier, page fetch and the orchestrated run are all built and
   tested — and `@growth-os/crawler` appears in no other package's dependencies,
   no worker job and no route. It is a complete subsystem nothing invokes. There
   is also **no HTML link extraction**, so a crawl discovers pages only from its
   seed and from sitemaps: a site with no sitemap yields a one-page crawl.

## 6. Documentation coverage

### The convention, established by reading before checking

Ten existing files were read first to determine the actual house style rather
than assume it. It is a top-of-file `/** … */` block; the strongest form opens
with a one-line summary and an **`ARCHITECTURAL RESPONSIBILITY`** section, often
followed by `⚠️`-prefixed paragraphs naming the specific failure the file
exists to prevent, and closing with `@see` links to ADRs. Barrel files carry a
shorter block or, in most cases, none.

The check applied: **does the file open with a block comment at all** — the
weakest possible bar, so the count is a floor.

### The measurement

Scope as briefed — every non-test `.ts`/`.tsx` in `packages/` and
`apps/web/src`, excluding `*.test.ts(x)` and `*.d.ts`, enumerated from
`git ls-files`.
